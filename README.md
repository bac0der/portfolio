# Dinamik Portfolio Sayt v1.1 (React + Tailwind CSS + Firebase)

Zamonaviy **Dark Mode & Glassmorphism** dizayniga ega, to'liq **Admin Panel** orqali boshqariladigan shaxsiy portfolio loyihasi.

## Yangi qo'shilgan imkoniyatlar (v1.1)
- **About & Profile bo'limi:** Tasdiqlangan shaxsiy portret rasmi (`public/profile.jpg`), bio ma'lumotlar va asosiy yo'nalishlar.
- **Contact bo'limi & Xabarlar Qutisi:** Foydalanuvchilar sayt orqali to'g'ridan-to'g'ri xabar yubora oladi; barcha kelgan xabarlar Admin Panelning **"Xabarlar"** bo'limida ko'rinadi.
- **Admin Panel (CRUD):** Loyihalar, ko'nikmalar va kelgan xabarlarni real vaqtda boshqarish.

## Ishga tushirish
```bash
npm install
npm run dev
```
